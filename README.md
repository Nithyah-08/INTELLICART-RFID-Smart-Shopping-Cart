# INTELLICART – RFID Smart Shopping Cart

## Overview
INTELLICART is an RFID-based smart shopping cart system designed to reduce checkout waiting time and improve shopping efficiency using embedded systems and RFID technology.

The project focuses on automating the billing process in supermarkets to provide a faster and smarter shopping experience.

## Features
- RFID-based product scanning
- Real-time LCD display updates
- Automated billing concept
- Real-time item detection
- Smart retail automation approach

## Components Used
- Arduino Nano
- EM-18 RFID Reader
- LCD Display
- Li-ion Battery
- Potentiometer
- Push Buttons
- Jumper Wires

## Software Used
- Arduino IDE
- Fusion 360

## Applications
- Smart retail systems
- Automated billing systems
- Inventory management
- Smart shopping solutions
